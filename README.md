# 出欠管理アプリ

座席表で欠席・遅刻・早退を入力するウェブアプリです。画面はブラウザで開きます。

保存の仕方は2つあります。GitHub Pages の版は、選んだフォルダの JSON だけに記録し、名簿をネットに送りません。スプレッドシート版は、デプロイした Google アカウントのスプレッドシートに保存します。家の Mac では個人アカウントだけで動作確認できます。学校では職場アカウントで別のスプレッドシートを作り直します。個人アカウントで作った URL は、職場アカウントでは開けません。試用の名簿は架空のものを使ってください。

## スプレッドシート版（個人アカウントで試す）

保存先は、その Google アカウントのスプレッドシートです。開けるのは、デプロイしたアカウントで Chrome にログインしているときだけです。

1. 個人アカウントでスプレッドシートを新規作成する（例: 出欠管理）
2. そのスプレッドシートで **拡張機能 → Apps Script** を開く  
   プロジェクトの設定にある **スクリプト ID** を控える
3. [Apps Script API](https://script.google.com/home/usersettings) をオンにする（同じアカウント）
4. このリポジトリで次を実行する

```bash
cd gas
cp .clasp.json.example .clasp.json
```

`.clasp.json` の `scriptId` を、控えたスクリプト ID に書き換える。

```bash
npx --yes @google/clasp login
node build.js
npx --yes @google/clasp push --force
```

`clasp login` は、試す個人アカウントでブラウザログインします。`push` はそのスプレッドシートに結び付いたスクリプトへ、画面と保存処理を送ります。

5. Apps Script の **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 実行ユーザー: **自分**
   - アクセスできるユーザー: **自分のみ**
6. 初回だけ、スプレッドシートへのアクセスを許可する
7. 表示された `/exec` の URL を、同じ Google アカウントでログインした Chrome で開く  
   右上は「保存先: スプレッドシート」になります。名簿は今までどおり Excel で読み込みます

コードを直したあとは、`gas` フォルダで `node build.js` と `npx --yes @google/clasp push --force` を実行し、**デプロイを管理** から同じデプロイを新しいバージョンに更新します。URL は変わりません。更新前の確認には、Apps Script のデプロイ画面にあるテスト用 URL（`/dev`）を使えます。自分のアカウントだけで、直前に push した内容が開きます。

家の Mac では個人アカウントしか使えません。上の手順はその確認用です。学校では個人アカウントにログインできないので、この URL は学校では開きません。

学校で試すときは、職場アカウントで新しいスプレッドシートを作り、`gas/dist` のファイルを Apps Script に貼って、ウェブアプリとしてデプロイし直します。手順は `school-kit/学校でやること.txt`、試用の名簿は `school-kit/サンプル名簿.xlsx` にあります。本物の名簿は、動作確認が終わったあとに、職場アカウントのスプレッドシートへだけ入れてください。

他の人に渡すときも、1人につき1つのコピーです。コピーした人が自分で一度デプロイします。名簿と出欠はコピーごとに分かれます。すでにコピーしたファイルへ、あとからの修正は自動では入りません。

## 先生向け（GitHub Pages）

1. Chrome または Edge で配布 URL を開く  
2. 初回だけ右上の **データフォルダ** を選び、保存先フォルダを指定する  
   - フォルダ内に `attendance-data.json` が作られます  
3. いつもどおり名簿読込 → 座席 → 出欠入力  
4. タブを閉じて開き直したときは、右上の **再接続** を押して同じフォルダへの許可を戻す（フォルダの選び直しは不要）

ポイント:

- インストール不要。exe / vbs / bat は使いません  
- データは端末のフォルダのみ。クラウドや外部 API には送りません  
- 同じフォルダを選べば、別の日・別のブラウザでも続きから使えます（許可ダイアログあり）

## 必要な環境

- Google Chrome または Microsoft Edge（フォルダ保存のため）
- 初回起動時はページ取得のためネット接続（その後のデータ保存は端末内）

## プライバシー（フォルダ保存の版）

- 名簿・出欠の保存先は、選んだデータフォルダ内の `attendance-data.json` だけです
- Excel の読込・出欠の計算はすべてブラウザ内で行います
- GitHub Pages に置いているのは HTML/CSS/JS（アプリ本体）だけです
- 画面表示のため、ブラウザ内（IndexedDB）にも名簿のコピーが残ります。年度末や共用パソコンの利用後は「データの削除」→「端末内バックアップ削除」で消去できます
- 外部送信を禁止する設定（Content-Security-Policy）をページに入れてあり、万一のスクリプト混入時にも名簿がネットに出ないよう多重化しています

## 使い方の流れ

1. **名簿データ** → 「名簿読み込み」で講座名を入力し、Excel を読み込む  
   - 1行目: 見出し  
   - A: 年次 / B: クラス / C: 出席番号 / D: 氏名  
   - サンプル: `data/sample_roster.xlsx`
2. **座席の設定** → 通し番号を座席（最大 横6×縦8）に割り当て →「決定」  
   - 一番下は教卓（教師視点）  
   - 間違えたら「undo」  
3. **出欠の入力** → 座席をタップ（欠席→遅刻→早退→出席）→「記録」  
4. **出欠の確認** → 欠席・遅刻・早退・停忌・公欠の累計  
5. **出欠の変更** → 日付ごとの表でプルダウン変更（停忌・公欠もここ）

## 同日に同じ講座が2回ある場合

「記録」を同日にもう一度押すと  
「すでに記録されています。加算しますか？」と聞きます。  
「はい」で 2 コマ目として別セッションを追加します。

## 注意

- `file://`（HTML をダブルクリック）ではフォルダ保存できません。https の配布 URL から開いてください
- 講座は最大 15 個です
- 名簿を上書きすると座席設定はクリアされます（通し番号の意味が変わるため）

## 開発者用（ローカルサーバー）

オフライン開発や API 経由の自動保存を使う場合:

```bash
# macOS / Linux
chmod +x start.sh
./start.sh
```

Windows では `AttendanceCheck.vbs` / `start.bat`（`server.exe`）も利用できます。  
ブラウザで `http://127.0.0.1:8787/` を開くと、`data/attendance-data.json` に自動保存されます。

## Windows 試作（専用ウィンドウ）

GitHub Pages が主配布です。学校 PC でオフライン起動を試す場合は、専用ウィンドウの exe もあります。

Mac / Linux で exe を作る:

```bash
chmod +x desktop/build.sh
./desktop/build.sh
```

成果物は `dist/AttendanceCheck.exe` です。この 1 ファイルを USB 等で Windows PC にコピーしてダブルクリックします。

- ブラウザは使わず、専用ウィンドウが開きます
- 名簿・出欠は exe と同じフォルダの `data/attendance-data.json` に自動保存されます（ネットには送りません）
- Pages 版で選んだデータフォルダとは別ファイルです。移すときは JSON をコピーしてください
- 未署名のため、SmartScreen で「Windows によって PC が保護されました」と出ることがあります。その場合は「詳細情報」→「実行」です
- Microsoft Edge（WebView2）が入っている Windows 10 / 11 が必要です
- ウイルス対策や学校の実行制限で止まる場合があります。動かなければ GitHub Pages の URL を使ってください

**学校への主配布には exe / vbs / bat を含めません**（Pages の URL を使います）。exe は試作・オフライン確認用です。
