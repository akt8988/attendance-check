出欠管理（スプレッドシート版）  学校で試す手順
2026年10月15日


アカウントの分かれ方

- 家の Mac では、個人の Google アカウントしか使えない
- 学校のパソコンでは、職場の Google アカウントしか使えない
- 個人アカウントで作った URL は、職場アカウントでは開けない
- 学校では、職場アカウントで新しく作り直す


持っていくもの

デスクトップのフォルダ「出欠管理-学校に持っていく」を、USB メモリにコピーする。
中身は次の2つ。

- 学校でやること.txt（この手順）
- サンプル名簿.xlsx（架空の名前）
- スクリプト（アプリの中身。11個のファイル）

USB が使えないときは、家の Mac からこのフォルダの zip を、職場のメールアドレスに送っておく。
学校では職場アカウントのメールからダウンロードする。
学校のパソコンで個人アカウントにはログインしない。

本物の生徒名簿や attendance-data.json は持っていかない。
試すあいだは、サンプル名簿だけを使う。


========================================
1. 家でできること（やらなくても学校では試せる）
========================================

家の Mac と個人アカウントで、同じアプリが動くか先に見ておくと安心です。
そこで作った URL は、学校には持っていきません。学校では使えません。
家での手順は、Attendance-Check の README にあります。


========================================
2. 学校でやること
========================================

Chrome は、職場の Google アカウントでログインした状態にします。

2-1. ネットの確認

□ アドレス欄に https://script.google.com と入れて、ページが開くか見る
  開かないときは、学校のネットが止めている。その日の試用はここまで

2-2. スプレッドシートを作る

□ Google スプレッドシートを新規作成する（名前の例: 出欠管理）
□ 「拡張機能」→「Apps Script」を開く
□ 最初から入っている Code.gs の文字を、全部消す

2-3. スクリプトを貼る

「出欠管理-学校に持っていく」の「スクリプト」フォルダを使う。
ファイルはメモ帳で開く。Word では開かない。
Apps Script の「ファイルを追加」（＋）で、種類と名前を合わせてから貼る。
名前を入れる欄に .html や .js は付けない。

□ Code.gs
  種類: 最初からあるスクリプト（追加しない）
  中身を「スクリプト」フォルダの Code.gs で全部置き換える

□ chunks
  種類: スクリプト
  名前: chunks
  中身は chunks.js

□ index
  種類: HTML
  名前: index
  中身は index.html

□ css
  種類: HTML
  名前: css
  中身は css.html

□ xlsx
  種類: HTML
  名前: xlsx
  中身は xlsx.html
  このファイルだけ大きい。貼り付けに少し時間がかかる。終わるまで待つ

□ storage
  種類: HTML
  名前: storage
  中身は storage.html

□ roster
  種類: HTML
  名前: roster
  中身は roster.html

□ seating
  種類: HTML
  名前: seating
  中身は seating.html

□ attendance
  種類: HTML
  名前: attendance
  中身は attendance.html

□ app
  種類: HTML
  名前: app
  中身は app.html

□ appsscript.json
  左の歯車（プロジェクトの設定）を開く
  「appsscript.json」マニフェスト ファイルをエディタで表示する、にチェックを入れる
  出てきた appsscript.json の中身を、フォルダの appsscript.json で全部置き換える
  保存する

2-4. ウェブアプリとして公開する

□ 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」
□ 実行ユーザー: 自分
□ アクセスできるユーザー: 自分のみ
□ 「デプロイ」を押す
□ 初回は「権限を確認」→ 職場アカウントを選ぶ → 「許可」
□ 表示された URL（末尾が /exec）をコピーする

2-5. 動くか試す

□ コピーした URL を、職場アカウントの Chrome で開く
□ 右上が「保存先: スプレッドシート」になっていることを確認する
  「データフォルダ」と出ているページは、別の版。その URL は使わない
□ 左の「名簿データ」→「名簿読み込み」
□ 講座名を入力する（例: 試し）
□ サンプル名簿.xlsx を選ぶ
  1行目は見出し。A 年次、B クラス、C 出席番号、D 氏名
□ 左の「座席の設定」で通し番号を座席に置き、「決定」
□ 左の「出欠の入力」で座席をタップし、「記録」
□ タブを閉じ、同じ URL をもう一度開く
□ 講座と、さっきの出欠が残っているか見る
  残っていれば、職場アカウントのスプレッドシートに保存できている

2-6. 終わるとき

□ 共有のパソコンなら、Chrome から職場アカウントをログアウトする
□ USB やダウンロードに置いたこのフォルダを、学校のパソコンに残さない


========================================
3. 学校ではやらないこと
========================================

- 個人の Google アカウントにログインしない
- 家で個人アカウントに作った URL を開かない
- 本物の生徒名簿を、この試用では読み込まない
  動いたことを確認したあとの本物の名簿は、職場アカウントのこのスプレッドシートにだけ入れる
- 「データフォルダ」「再接続」がある画面は、今回の試用ではない
