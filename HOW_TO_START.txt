出欠管理アプリ — 使い方
======================

【先生向け】ブラウザで開く（推奨）
--------------------------------
1. Chrome または Edge で配布 URL を開く
2. 初回だけ「データフォルダ」を選び、保存先フォルダを指定する
3. 名簿・出欠はそのフォルダ内の attendance-data.json に保存される
   （ネットには送らない）

必要環境:
- Google Chrome または Microsoft Edge
- 初回はページ取得のためネット接続

【開発者用】ローカルサーバー（任意）
----------------------------------
オフライン開発や自動保存 API を使う場合のみ。

Windows:
  AttendanceCheck.vbs ... 背面起動
  start.bat           ... コンソール付き起動
  stop.bat            ... 背面サーバー停止
  → http://127.0.0.1:8787/

macOS / Linux:
  ./start.sh
  → http://127.0.0.1:8787/

学校への配布では exe / vbs / bat は使いません。
